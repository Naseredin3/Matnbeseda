# سامانه تبدیل متن به گفتار فارسی سلیس و روان (Persian Fluent TTS)

این پروژه مجهز به موتور هوش مصنوعی صوتی پیشرفته Gemini TTS، موتور پشتیبان مرورگر برای خوانش فوری، و قابلیت استخراج خودکار **برنامه نصبی اندروید (APK)** از طریق GitHub Actions است.

---

## ۱. رفع خطای اکشن‌های گیت‌هاب (Fix GitHub Actions Error)

خطای قبلی در گیت‌هاب به دلیل جستجوی فایل قفل وابستگی‌ها (`package-lock.json`) و کش اجباری در تسک `setup-node` رخ می‌داد. این مشکل به طور کامل رفع شد:
- فایل `package-lock.json` به ریشه پروژه اضافه شد.
- تنظیمات گردش‌کار CI (`ci.yml`) بهینه‌سازی شد تا نیازمندی اجباری به کش پکیج نداشته باشد و دستور `npm install --prefer-offline --no-audit` بدون هیچ خطایی اجرا شود.
- مجوزهای دسترسی (`permissions: contents: read/write`) به صورت صریح تعریف شدند.

---

## ۲. نحوه استخراج و دانلود فایل برنامه اندروید (APK)

یک اکشن اختصاصی تحت عنوان **`android-apk.yml`** در مسیر `.github/workflows/android-apk.yml` افزوده شده است که فایل نصبی اندروید (`.apk`) را به صورت کاملاً خودکار می‌سازد:

### روش دانلود آسان فایل APK از گیت‌هاب:
1. وارد ریپازیتوری خود در GitHub شوید.
2. روی تب **Actions** در بالای صفحه کلیک کنید.
3. از ستون سمت چپ، گردش‌کار **Build & Export Android APK** را انتخاب کنید.
4. روی آخرین بیلد سبز رنگ (تکمیل شده) کلیک کنید.
5. در انتهای صفحه بیلد، در بخش **Artifacts**، روی فایل **`Persian-TTS-Android-APK`** کلیک کنید تا فایل zip حاوی برنامه نصبی اندروید دانلود شود.
6. فایل را از حالت فشرده خارج کرده و `Persian-TTS-Assistant.apk` را مستقیماً روی گوشی اندرویدی خود نصب کنید!

> **نکته:** هر زمان تمایل داشتید بدون ارسال کامیت فایل APK جدید بسازید، در تب **Actions** روی **Build & Export Android APK** کلیک کرده و دکمه **Run workflow** را بزنید.

## ۳. تعیین کلید دائمی برای برنامه (Permanent API Key)

برای اینکه برنامه چه در مرورگر وب و چه در قالب اپلیکیشن نصبی اندروید بدون قطعی یا نیاز به تنظیم مداوم کار کند، امکان تعیین **کلید دائمی (Permanent Key)** اضافه شده است:

### روش اول: تنظیم از داخل خود برنامه (ساده‌ترین روش - برای وب و اندروید)
1. در بالای صفحه برنامه، روی دکمه **«تعیین کلید دائمی»** کلیک کنید.
2. پنجره تنظیمات باز می‌شود.
3. کلید دسترسی Gemini API خود را وارد کنید.
4. دکمه **«تست اعتبار کلید»** را بزنید تا برنامه با سرور گوگل ارتباط برقرار کرده و از صحت کلید مطمئن شود.
5. روی **«ذخیره دائمی کلید»** بزنید.
6. این کلید در حافظه دائمی دستگاه شما ذخیره شده و از این پس تمامی تبدیل‌های صوتی و ویرایش‌های متن با این کلید انجام می‌شود.

### روش دوم: دریافت کلید دائمی و رایگان از گوگل (مادام‌العمر)
1. به آدرس پرتال گوگل [Google AI Studio (API Keys)](https://aistudio.google.com/app/apikey) بروید.
2. با حساب کاربری جیمیل خود وارد شوید.
3. روی دکمه **«Create API key»** کلیک کنید.
4. کلید تولید شده (معمولاً با `AIzaSy...` شروع می‌شود) را کپی کرده و در برنامه وارد کنید. این کلید کاملاً رایگان است و سهمیه سخاوتمندانه‌ای در اختیارتان می‌گذارد.

### روش سوم: تنظیم به عنوان متغیر محیطی در هاست یا گیت‌هاب
اگر پروژه را روی سرور (داکر، رندر، کلودران و...) دیپلوی می‌کنید:
1. در گیت‌هاب به مسیر **Settings** > **Secrets and variables** > **Actions** بروید.
2. یک Secret جدید با نام `GEMINI_API_KEY` ساخته و کلید خود را در آن قرار دهید.
3. همچنین در فایل `.env` سرور خود می‌توانید مقدار `GEMINI_API_KEY=your_key_here` را تنظیم نمایید.

## ۴. ویژگی‌های گویندگان و موتور صوتی
- **صدای Fenrir**: کالیبره‌شده برای صدای بم، باصلابت، رسا و مردانه به زبان فارسی.
- **سایر گویندگان**: Puck (مرد جوان و شاداب)، Charon (مرد فاخر و پخته)، Kore (زن گرم و دلنشین)، Zephyr (زن ملایم و آرامش‌بخش) و...
- **موتور مرورگر (Fallback)**: در صورت بروز هرگونه اختلال اینترنتی، قابلیت خوانش فوری آفلاین از طریق موتور صوتی داخلی دستگاه فعال است.
